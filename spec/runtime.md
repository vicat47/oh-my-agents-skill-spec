# 运行时契约

skill 必须说明一次调用接受什么输入、如何确定目标、成功返回什么、失败时停在哪里。不能唯一定位请求的实例时，不得猜测或使用其他实例。涉及外部环境时，执行前核对实际会话和所选目标；所有环境默认按生产标准操作，实例和 skill 可针对动作进一步收紧。直接运行脚本也必须遵守其支持范围。

声明调用会读写什么；重试可能重复产生副作用时，要告诉调用方如何判断上次操作是否已经完成。

| 工件 | 规则与删除后果 |
|---|---|
| 单次运行记录 | 需要时才写，按调用隔离；两次调用不能覆盖彼此记录。 |
| 跨次状态 | 声明用途、归属及恢复边界；删除会失去进度。 |
| 缓存 | 可以重建；清空不能改变用户选择或删除正式结果。 |
| 交付结果 | 返回给调用方或写到约定的输出位置；清理缓存或日志不能删除用户结果。 |

只读查询可以把结果直接返回。验收时至少检查成功、失败、重复运行三种情况，以及项目配置和包内文件是否保持不变（明确用于修改项目配置的动作除外）。
