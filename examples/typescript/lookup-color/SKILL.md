# 查询调色板颜色

1. 确认项目的 TOML 文件和要查的名称。文件不明确时先询问；不要用演示文件替代用户的项目。
2. 使用 Node.js 24。初次使用时在本包目录运行 `npm ci`。查询入口是本包的 `scripts/lookup.ts`；项目文件路径相对于**调用时的工作目录**。例如，从本包查询随附的虚构项目：

   ```sh
   node scripts/lookup.ts demo/project.toml mint
   ```

3. 脚本按[项目总 Schema](schemas/project.schema.json)校验整个 `[palette]` 表，再按名称精确匹配（区分大小写）。成功时原样返回标准输出的一行 `#RRGGBB`，即告结束。
4. 找不到文件、配置无效或名称不存在时，转述标准错误中的原因并停止；不要猜测近似色或补写配置。只有输入或文件得到修正后才需要重试。

查询不联网，不写文件；同一配置和名称可重复查询。要求改色时不调用脚本。
